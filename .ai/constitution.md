# CONSTITUTION

## Principios
1. Mobile first.
2. Domain Driven Design.
3. Clean Architecture.
4. SOLID.
5. Event Driven cuando aporte valor.
6. Código documentado y testeado.
7. Todo módulo debe incluir API, UI, DB y tests.
8. IA basada en metodología Sailvex.
9. Multi idioma (ES/EN).
10. Diseño preparado para múltiples clases olímpicas.
